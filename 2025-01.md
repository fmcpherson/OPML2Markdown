- Searching For Readwise Reader Tags In Obsidian
  - I use Readwise Reader for reading web article, and in some instances when I read an article I may assign it a document tag. One way that I use these tags is to flag articles that could be a source for a blog post/essay. I've wished for a way to export just the tagged articles and today I realize that I have something similar already working with Obsidian.
  - I have synchronization between Readwise and Obsidian so that all article, which come from Readwise Reader, and book (which come from Kindle) highlights are stored in my Obsidian vault. I realized today that the tags I am using appear in the Metadata section of an article that I highlight. The problem is that these "tags" in the metadata are not prepended with a hash (oddly, Readwise is using hash to flag categories rather than tags) but instead they are added as wiki links. If I click the "tag" link in one of the article documents a new file is added to my vault with that name and all of the articles with that tag are in the Linked mentions section of the document.
  - I think I like how this is working in Obsidian. To make it work better I changed the backlinks core plugin to display all the backlinks at the bottom of notes.
