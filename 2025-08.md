## August 2025

### August 29
- While reading <a href="https://inessential.com/2025/08/28/easy-app-writing.html">Brent's description of how he programmed in the 90s</a> using UserLand Frontier I immediately thought of <a href="https://newtonscript.org/">NewtonScript</a>. Apple had much innovation in <a href="https://www.youtube.com/watch?app=desktop&v=5kxRi34PqWo&t=36s">Newton</a> that got overlooked and how apps were developed and ran on <a href="https://en.wikipedia.org/wiki/Newton_OS">the operating system</a> is one. Newton OS even had <a href="https://en.wikipedia.org/wiki/Soup_(Apple)">a database based file system</a> that optimized sharing across applications to prevent redundancy. I think the Newton files system was not only needed due to the constraints of limited physical storage but also to enable fast and easy application development like Brent describes.
- I think that what Brent describes in his post about Frontier's database for persistent storage is why <a href="http://scripting.com">Dave</a> always <a href="https://daytona.scripting.com/search?q=storage">emphasizes the need for a common storage</a> platform on the Internet. I've seen Dave struggle through this over the years from using Dropbox and then AWS. Problem seems that we continue to be stuck on the original file structure developed in the CP/M and Unix days with very little innovation ever since. Microsoft seemed to try with <a href="https://en.wikipedia.org/wiki/WinFS">WinFS</a> but that never came to fruition and it seems that the industry just gave up.
